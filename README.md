# Ruby Smythe portfolio

A static Astro portfolio for Ruby Smythe's tattoo, drawing, and painting work.

## Commands

    corepack pnpm install
    corepack pnpm check
    corepack pnpm build
    corepack pnpm exec astro dev --background

Use the Astro dev status, logs, and stop commands through Corepack's pnpm to
manage the background development server.
